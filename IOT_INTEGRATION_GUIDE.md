# IoT Integration Guide

## Overview
This backend now supports IoT device integration for real-time data collection from vehicles and sensors.

## Available Endpoints

### 1. Send IoT Data
**POST** `http://localhost:5000/api/v1/iot/data`

Send sensor data from your IoT device to the backend.

**Headers:**
- `Authorization: Device YOUR_DEVICE_ID` (for development)
- `X-API-Key: YOUR_API_KEY` (alternative)

**Request Body:**
```json
{
  "deviceId": "GPS001",
  "deviceType": "GPS_TRACKER",
  "vehicleId": "60f7b3b3b9b3b3b3b3b3b3b3",
  "location": {
    "latitude": -1.2921,
    "longitude": 38.8219,
    "altitude": 1700,
    "speed": 45,
    "heading": 90,
    "accuracy": 10
  },
  "sensorData": {
    "temperature": 75.5,
    "humidity": 65,
    "fuelLevel": 85,
    "batteryVoltage": 12.6,
    "engineStatus": true,
    "odometer": 15420
  },
  "deviceStatus": {
    "batteryLevel": 85,
    "signalStrength": 4,
    "isActive": true
  }
}
```

### 2. Get Device Data
**GET** `http://localhost:5000/api/v1/iot/device/:deviceId`

Retrieve historical data for a specific device.

**Query Parameters:**
- `limit`: Number of records (default: 100)
- `page`: Page number (default: 1)
- `startDate`: Filter start date (ISO string)
- `endDate`: Filter end date (ISO string)

### 3. Get All Devices
**GET** `http://localhost:5000/api/v1/iot/devices`

Get overview of all registered IoT devices.

### 4. Get Analytics
**GET** `http://localhost:5000/api/v1/iot/analytics`

Get analytics and statistics for IoT data.

**Query Parameters:**
- `deviceId`: Filter by device ID
- `vehicleId`: Filter by vehicle ID
- `period`: Time period (1h, 24h, 7d, 30d)

### 5. Get Alerts
**GET** `http://localhost:5000/api/v1/iot/alerts`

Get device-generated alerts.

**Query Parameters:**
- `deviceId`: Filter by device ID
- `vehicleId`: Filter by vehicle ID
- `severity`: Filter by severity (LOW, MEDIUM, HIGH, CRITICAL)
- `type`: Filter by alert type

## Device Types Supported

- `GPS_TRACKER`: Location and movement data
- `TEMPERATURE_SENSOR`: Temperature monitoring
- `HUMIDITY_SENSOR`: Humidity monitoring
- `FUEL_SENSOR`: Fuel level monitoring
- `SPEED_SENSOR`: Speed monitoring
- `MULTI_SENSOR`: Combined sensor data

## Authentication Methods

### Development Mode
Use any string as your device ID:
```bash
curl -X POST http://localhost:5000/api/v1/iot/data \
  -H "Authorization: Device GPS001" \
  -H "Content-Type: application/json" \
  -d '{"deviceId":"GPS001","location":{"latitude":-1.2921,"longitude":38.8219}}'
```

### Production Mode
Use JWT tokens generated by the system.

## Integration Examples

### Arduino/ESP32 Example
```cpp
#include <WiFi.h>
#include <HTTPClient.h>
#include <ArduinoJson.h>

void sendIoTData() {
  HTTPClient http;
  http.begin("http://localhost:5000/api/v1/iot/data");
  http.addHeader("Content-Type", "application/json");
  http.addHeader("Authorization", "Device GPS001");
  
  StaticJsonDocument<200> doc;
  doc["deviceId"] = "GPS001";
  doc["deviceType"] = "GPS_TRACKER";
  doc["vehicleId"] = "60f7b3b3b9b3b3b3b3b3b3b3";
  
  JsonObject location = doc.createNestedObject("location");
  location["latitude"] = -1.2921;
  location["longitude"] = 38.8219;
  location["speed"] = 45;
  
  String jsonString;
  serializeJson(doc, jsonString);
  
  int httpResponseCode = http.POST(jsonString);
  http.end();
}
```

### Python Example
```python
import requests
import json

def send_iot_data():
    url = "http://localhost:5000/api/v1/iot/data"
    headers = {
        "Authorization": "Device GPS001",
        "Content-Type": "application/json"
    }
    
    data = {
        "deviceId": "GPS001",
        "deviceType": "GPS_TRACKER",
        "location": {
            "latitude": -1.2921,
            "longitude": 38.8219,
            "speed": 45
        },
        "sensorData": {
            "temperature": 75.5,
            "fuelLevel": 85
        }
    }
    
    response = requests.post(url, headers=headers, json=data)
    return response.json()
```

### Node.js Example
```javascript
const axios = require('axios');

async function sendIoTData() {
  try {
    const response = await axios.post('http://localhost:5000/api/v1/iot/data', {
      deviceId: 'GPS001',
      deviceType: 'GPS_TRACKER',
      location: {
        latitude: -1.2921,
        longitude: 38.8219,
        speed: 45
      },
      sensorData: {
        temperature: 75.5,
        fuelLevel: 85
      }
    }, {
      headers: {
        'Authorization': 'Device GPS001',
        'Content-Type': 'application/json'
      }
    });
    
    console.log('Data sent successfully:', response.data);
  } catch (error) {
    console.error('Error sending data:', error.message);
  }
}
```

## Real-time Features

The IoT integration includes:
- **WebSocket Broadcasting**: Real-time updates to connected clients
- **Automatic Vehicle Location Updates**: Updates vehicle locations in the database
- **Alert Generation**: Automatic alerts for critical conditions
- **Data Validation**: Input validation for all sensor data
- **Rate Limiting**: Protection against data flooding

## Alert Types

- `LOW_BATTERY`: Device battery below 20%
- `HIGH_SPEED`: Vehicle speed exceeds limits
- `FUEL_LOW`: Fuel level below 15%
- `TEMPERATURE_HIGH`: Engine temperature too high
- `DEVICE_OFFLINE`: Device hasn't sent data recently
- `GEOFENCE_BREACH`: Vehicle outside designated area
